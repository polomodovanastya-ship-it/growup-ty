# Architecture Decision Records (ADR)

Важные архитектурные и технические решения фиксируем в ADR — коротких документах с контекстом, выбором и последствиями.

Процесс описан в [ADR-0001: Использование Architecture Decision Records](./0001-use-architecture-decision-records.md).

## Быстрый старт

1. Скопируйте [шаблон](./template.md) в новый файл: `NNNN-краткое-название-на-английском.md`.
2. Заполните разделы, начните со статуса **Предложен**.
3. Обсудите в PR или в чате команды.
4. После согласования смените статус на **Принят** и добавьте строку в таблицу выше.
