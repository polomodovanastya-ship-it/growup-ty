# Блок «Что поможет» после теста KIDSCREEN

Сейчас после результатов показывается экран «Что можно сделать» — просто один абзац текста на каждую сниженную сферу. По документу нужно превратить его в блок «Что поможет» с тремя типами рекомендаций, библиотекой из 16 практик и отдельным блоком «Дыхание».

## Что увидит подросток

1. **Экран профиля** (без изменений) → кнопка «Далее».
2. **Экран «Что поможет»** — карточка на каждую сферу, требующую внимания (уровни «ниже среднего» и «низкий»; если таких нет — 2–3 сферы с наименьшим результатом). Внутри карточки три части:
   - **Послушать / почитать** — ссылка на подкаст или статью сайта (для сфер без материала пункт не показывается).
   - **Попробовать** — короткая практика из документа (например, «Я — это больше, чем…»).
   - **Следующий шаг** — действие в реальной жизни (поговорить, попросить помощи).
3. **Кнопка «Ещё способы»** внутри карточки — раскрывает 2–4 практики из библиотеки, подобранные по тегам сферы. Практика показывается в формате: зачем пробовать → что сделать → что заметить после.
4. **Блок «Дыхание»** — отдельная карточка внизу экрана (Медленное дыхание, Дыхание по ладони, Дыхание по квадрату, Вдох-выдох с облегчением). Показывается для сфер, где документ его предусматривает.
5. **«Помощь рядом»** — постоянная плавающая кнопка справа на экранах результата и рекомендаций, ведёт на /help.
6. **Приоритет помощи при риске**: если у сферы уровень «низкий» (особенно «Общее состояние», «Чувства», «Что ты думаешь о себе»), над практиками показывается блок «Стоит поговорить с человеком» со ссылкой на «Помощь рядом» — практики идут ниже, а не вместо.

Формулировки «3 шага» не используем — это блок «Что поможет» с выбором.

## Ранжирование практик

Каждая практика имеет основные и дополнительные сферы (теги из документа). Порядок выдачи: сначала практики, релевантные сразу нескольким сниженным сферам, затем по основному тегу, затем по дополнительному. На первом экране — короткая выдача, остальное под «Ещё способы».

## Технические детали

- Новый файл `src/kidscreen/practices.ts`: 16 практик (`id`, `title`, `why`, `what`, `notice`, `primaryScales`, `secondaryScales`) + блок дыхания (4 техники).
- Новый файл `src/kidscreen/whatHelps.ts`: по каждой из 10 сфер — `listen` (заголовок + ссылка на существующий подкаст/статью, если есть), `try`, `nextStep`, флаг `breathing`.
- `src/kidscreen/recommendations.ts` остаётся как текст «подробнее» на экране профиля — не трогаем.
- Функция подбора практик по профилю (ранжирование выше) — в `whatHelps.ts`, чистая, без обращения к БД.
- `src/components/KidscreenQuiz.tsx`: экран `recommendations` переписывается на новую верстку (карточки сфер, раскрывающийся «Ещё способы», блок «Дыхание», плавающая кнопка «Помощь рядом»). Стилистика — существующие карточки сайта.
- PDF-отчёт: в отчёт добавляются те же «Что поможет» по сферам (без библиотеки практик, чтобы не раздувать файл).
- Изменений в БД и edge-функциях не требуется.

## Что вне этого этапа

- Интерактивные анимации дыхания (движущаяся точка), «рисовалка», сохранение выбранного «для себя» — карточки пока текстовые с инструкцией «возьми бумагу или открой заметки».
- Недостающие материалы для колонки «Послушать/почитать» (деньги, перегрузка в учёбе, границы, «Когда ничего не хочется», тело и восстановление) — отдельные статьи, можно сделать следующим шагом.
