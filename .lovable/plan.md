

## «Как ты» — редизайн сайта

Минималистичный, воздушный сайт для подростков и молодых взрослых о ментальном здоровье. Спокойная палитра, умеренное пространство (не раздутое — хорошо на мобильных), лёгкие анимации при скролле.

### Дизайн-система

- **Палитра**: тёплый белый фон (#FAFAF8), акцент — мягкий индиго (#6366F1), вторичный — мятный (#34D399), текст — тёмно-серый (#1E293B)
- **Типографика**: Inter для всего, жирные заголовки
- **Скругления**: крупные (12-16px для карточек, pill для кнопок/тегов)
- **Отступы**: умеренные — py-12/py-16 на десктопе, py-8 на мобильных. Компактно, но не тесно

### Структура (один файл Index.tsx + вспомогательные компоненты)

**Hero**
- Заголовок «Привет, как ты?» + короткий подзаголовок неформальным тоном
- Теги-пилюли с темами (тревога, прокрастинация, отношения и т.д.) — fade-in при загрузке
- CTA-кнопка
- 2-3 декоративных blob-формы на фоне (CSS, absolute positioned, blur)

**«Послушай» (подкасты)**
- Сетка карточек (1 колонка мобайл, 2-3 десктоп)
- Карточка: иконка, название, короткое описание, статус
- Fade-in при скролле

**«Разберись» (чекапы) + «Действуй» (чеклисты)**
- Два блока (стек на мобайле, рядом на десктопе)
- Списки элементов с hover-эффектами
- Иконки для каждого пункта

**Футер**
- Минимальный, одна строка с поддерживающим сообщением

### Анимации
- Intersection Observer: fade-in + slide-up (translate-y 20px) при появлении секций
- Hover на карточках: мягкий scale(1.02) + усиление тени
- Blob-формы: медленная CSS-анимация (движение/морфинг)

### Файлы для изменения
1. **src/index.css** — новые CSS-переменные палитры, анимации blob и fade-in
2. **src/pages/Index.tsx** — полная замена на новую страницу со всеми секциями
3. **src/components/ScrollReveal.tsx** — компонент-обёртка с Intersection Observer
4. **src/App.css** — удалить неиспользуемые стили

### Адаптивность
- Все отступы через responsive-классы (py-8 md:py-12 lg:py-16)
- Сетки: grid-cols-1 на мобайле, sm:grid-cols-2, lg:grid-cols-3
- Теги в hero — flex-wrap, не overflow
- Blob-формы уменьшаются/скрываются на мобайле
